# any-co — demo pitch

Working draft for the Sunday 1:00 PM presentation. Judges score how much of the company ran without a person. Source of the claim is `docs/plan.md` §1 and §8.

## One-liner

**any-co is a game studio run by agents: a budget and the Steam catalog in, a shipped game out, and every human touch on the ledger.**

Say that, then stop. The rest of the demo is proof of the last clause.

### If the room needs a shorter line

A game studio that runs itself. You can count every time a person touched it.

### If they ask what you built

The harness: the roster, the board, the gates, and the ledger. The game was made by the studio after kickoff. Ty did not write the concept, the design, the art, the code, or the store copy.

## Thirty seconds

We started the studio with a budget and the Steam catalog. Agents found a gap, picked a game, designed it, made the art and the code, tested it, marketed it, and put a public build up. A person only did what a platform requires a person to do: identity and payment setup. Each time someone stepped in after that, the ledger has the action and the reason.

## What "shipped" means here

Steam cannot release a new game this weekend. By freeze we show:

- A playable web build and a landing page on the studio site.
- A live itch.io page, downloadable, priced or pay-what-you-want.
- A Steam store page submitted for review, Windows build uploaded, release date set.
- Devlog, posts, and outreach that went out.
